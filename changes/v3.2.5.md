## v3.2.5

### Added
- `RegulaError` class exposing `stdout`, `stderr`, `exitCode`, and `command` on failures

### Changed
- `runRegula()` no longer writes stderr to the console; callers receive it on `RegulaError` instead
- Exit code 1 is treated as success, since regula uses it to signal policy violations rather than execution failure

### Fixed
- stderr from OPA errors is now reachable by callers instead of being swallowed
